# Цель работы

Цель лабораторной работы — изучить метод опорных векторов (SVM), разобраться, как параметр C и разные ядра влияют на разделение классов, а также научиться применять этот метод для решения задачи бинарной классификации.

# Ход работы

Для работы был использован датасет `bank.csv`, содержащий банковские данные о клиентах. Для классификации выбраны два признака: `age` (возраст клиента) и `balance` (баланс на счёте). Целевая переменная `deposit` со значениями `"yes"` и `"no"` была преобразована в числа 1 и 0.

Данные разделены на обучающую и тестовую выборки в соотношении 80/20 с сохранением пропорций классов. Обучающая выборка содержит 8929 объектов, тестовая — 2233 объекта. Доля класса `1` в обучающей выборке составила 0.4738. Перед обучением признаки были масштабированы с помощью `StandardScaler`.

Затем были обучены две модели SVM: с линейным ядром и RBF-ядром. Для обеих моделей использовались параметры `C=1.0` и `gamma="scale"`. Качество оценивалось с помощью точности, отчёта классификации и матрицы ошибок.

Дополнительно было определено количество опорных векторов для RBF-модели и предпринята попытка проверить влияние параметра C при значениях 0.01 и 1000.

# Результаты

Точность линейной модели SVM составила 52.89%, а модели с RBF-ядром — 60.05%. Таким образом, RBF-модель показала лучший результат.

По отчёту классификации RBF-модели для класса `0` precision составил 0.592, recall — 0.773, f1-score — 0.671. Для класса `1` получены значения 0.619, 0.409 и 0.493 соответственно.

Матрица ошибок показала следующие результаты: правильно определено 908 объектов класса `0` и 433 объекта класса `1`. При этом 267 объектов класса `0` ошибочно отнесены к классу `1`, а 625 объектов класса `1` — к классу `0`.

Для RBF-модели найдено 7415 опорных векторов из 8929 объектов обучающей выборки, что составляет 83%. По классам их распределение составило `[3700, 3715]`. Это говорит о том, что разделить два класса по выбранным признакам достаточно сложно.

# Выводы

В ходе работы было установлено, что RBF SVM показывает более высокую точность по сравнению с линейной моделью. Это может говорить о том, что нелинейная модель лучше описывает зависимость между возрастом, балансом счёта и целевой переменной `deposit`.

При этом качество классификации остаётся умеренным. Модель лучше распознаёт класс `0`, чем класс `1`.

Большое количество опорных векторов также показывает, что разделение классов является непростой задачей. Эксперимент с параметром C пока не позволил сделать правильные выводы, так как при расчёте точности для разных значений параметра использовались предсказания одной и той же базовой модели.

Таким образом, RBF-ядро показало лучший результат, чем линейное, однако для улучшения качества классификации требуется дополнительная настройка параметров модели.
