# Цель работы

Целью лабораторной работы является освоение математической и геометрической интуиции метода опорных векторов (SVM), изучение влияния гиперпараметра C, задающего мягкий зазор, и ядерного трюка (Kernel Trick) на построение разделяющей гиперплоскости, а также приобретение практических навыков применения SVM для решения экономических задач бинарной классификации и интерпретации роли опорных векторов.

# Ход работы

Был взят датасет `bank.csv`,содержащий банковские данные. Для классификации выбраны два числовых признака: `age` (возраст клиента) и `balance` (баланс на счёте), а целевая переменная `balance` со значениями `"yes"` и `"no"` была перекодирована в `1` и `0` 

После разделения на обучающую и тестовую выборки в пропорции 80% на 20% со стратификацией по целевому классу были получены обучающая выборка размером 8929 объектов и тестовая выборка размером 2233 объекта. Доля класса `1` в обучающей выборке составила 0.4738. Перед обучением признаки были масштабированы с помощью `StandardScaler`

Затем были обучены две модели SVM — с линейным ядром и с RBF-ядром — при параметрах C=1.0 и gamma="scale". Качество моделей оценивалось по точности, отчёту классификации и матрице ошибок. Дополнительно для RBF-модели было проанализировано количество опорных векторов и их распределение по классам. Также была предпринята попытка исследовать влияние параметра C на линейный SVM при значениях 0.01 и 1000

# Результаты

Точность линейного SVM составила 52.89%, тогда как RBF SVM показал точность 60.05%. Таким образом, нелинейное RBF-ядро оказалось заметно лучше линейного на выбранных признаках. Для RBF-модели отчёт классификации показал следующие значения: для класса `0` precision составил 0.592, recall — 0.773, f1-score — 0.671; для класса `1` precision составил 0.619, recall — 0.409, f1-score — 0.493. Общая accuracy по отчёту равна 0.601, macro avg — 0.605 по precision, 0.591 по recall и 0.582 по f1-score, weighted avg — 0.605, 0.601 и 0.586 соответственно. Матрица ошибок для RBF-модели имеет вид: истинно отрицательных — 908, ложно положительных — 267, ложно отрицательных — 625, истинно положительных — 433

Для RBF-модели было получено 7415 опорных векторов из 8929 объектов обучающей выборки, что составляет 83.0%. Распределение опорных векторов по классам `[0, 1]` равно `[3700, 3715]`. Первые десять индексов опорных векторов в обучающей выборке: `[6, 8, 10, 12, 13, 14, 15, 18, 19, 21]`. Столь большая доля опорных векторов указывает на сложность разделения классов в выбранном признаковом пространстве

# Вывод

В ходе работы было установлено, что RBF SVM показывает более высокую точность по сравнению с линейным SVM, что говорит о нелинейном характере зависимости между признаками `age`, `balance` и целевой переменной `deposit`

При этом качество классификации остаётся умеренным: класс `0` распознаётся лучше, чем класс `1`, о чём свидетельствует более высокий recall для класса `0`

Большое количество опорных векторов свидетельствует о сложности задачи и возможной склонности модели к переобучению. Эксперимент с параметром \( C \) в текущем виде не позволил сделать корректные выводы из-за вероятной ошибки в расчёте метрик: для всех значений \( C \) использовались предсказания базовой линейной модели
