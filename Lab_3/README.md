# Лабораторная работа №3
Цель: построить и обучить модель машинного обучения, которая по данным о клиентах страховой компании определяет, является ли страховка дорогой, а также прогнозирует саму сумму расходов на страховку.

Для анализа был взят датасет insurance.csv с информацией о клиентах медицинской страховки. Каждая строка в нём соответствует одному клиенту, а столбцы содержат его возраст (age), пол (sex), индекс массы тела (bmi), количество детей (children), факт курения (smoker), регион проживания (region) и сумму страховых выплат (charges). На основе последнего столбца был сформирован бинарный целевой признак is_expensive, где 1 означает выплату выше медианы, а 0 — ниже. Классы получились сбалансированными, по 50 % на каждый, а сам столбец charges был удалён из обучающей матрицы, чтобы не допустить утечки данных.

Бизнес-задача заключается в прогнозировании категории страховки клиента на основе его демографических данных, образа жизни и региона проживания. Это позволит страховой компании быстрее выделять клиентов с высокими рисками и точнее рассчитывать тарифы. Дополнительно решается задача регрессии, то есть прогнозирование конкретной суммы страховых выплат.

Перед обучением модели данные нужно было подготовить. Числовые признаки (age, bmi, children) сначала заполняются медианой и масштабируются, категориальные (sex, smoker, region) заполняются самым частым значением и кодируются. 

Для классификации использован алгоритм KNN (KNeighborsClassifier). Его параметры n_neighbors и weights подбирались через GridSearchCV с 5-блочной стратифицированной кросс-валидацией по метрике ROC-AUC. Лучшими оказались n_neighbors = 9 и weights = 'distance'.

На тестовой выборке модель показала Accuracy 90 % и ROC-AUC 0,9405. Точность (precision) и полнота (recall) по обоим классам находятся в диапазоне 0,87–0,94, то есть модель почти не ошибается при определении дорогой и дешёвой страховки. Матрица ошибок выглядит так: 126 верно определённых дешёвых страховок, 116 дорогих, 8 ложноположительных и 18 ложноотрицательных.

Для прогнозирования суммы выплат был обучен KNeighborsRegressor на том же препроцессоре. Гиперпараметры подбирались через RandomizedSearchCV с 5-блочной кросс-валидацией KFold по метрике neg_mean_absolute_error. Лучшими оказались n_neighbors = 4 и weights = 'distance'.

Модель регрессии показала MSE = 34 114 812, RMSE = 5 841, MAE = 3384,67 и SMAPE = 28,77 %. Средняя ошибка около 3,4 тыс. долларов. SMAPE 28,77 % говорит о том, что модель улавливает общий тренд, но для точных прогнозов по каждому клиенту её нужно улучшать.

На графике «Ожидание и реальность» точки расположены вдоль диагонали, но с заметным разбросом: модель занижает крупные выплаты и слегка завышает мелкие. Гистограмма остатков смещена вправо от нуля, то есть модель чаще недооценивает реальные расходы.

В итоге модель классификации показала хорошее качество (90 % accuracy, ROC-AUC 0,94) и может применяться для предварительного скоринга клиентов. Модель регрессии даёт приемлемую, но не высокую точность: RMSE около 5,8 тыс. долларов и SMAPE около 29 %, чего недостаточно для точного расчёта тарифов. Основное ограничение в том, что KNN плохо работает с разными масштабами и слабо улавливает нелинейные зависимости. Для улучшения стоит попробовать градиентный бустинг, добавить новые признаки (например, взаимодействие bmi и smoker) и подобрать более широкую сетку гиперпараметров.
