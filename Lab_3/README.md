# Лабораторная работа №3
Цель: построить и обучить модель машинного обучения, которая по данным о клиентах страховой компании определяет, является ли страховка дорогой, а также прогнозирует саму сумму расходов на страховку

Для анализа был взят Medical cost personal datasets с информацией о клиентах медицинской страховки. Каждая строка в нём соответствует одному клиенту. Столбцы содержат возраст (age), пол (sex), индекс массы тела (bmi), количество детей (children), факт курения (smoker), регион проживания (region) и сумму страховых выплат (charges). На основе последнего столбца сформирован бинарный целевой признак is_expensive (1 означает выплату выше медианы, 0 означает ниже медианы). Классы получились сбалансированными, по 50 % на каждый. Столбец charges удалён из матрицы, чтобы не допустить утечки данных

Бизнес-задача заключается в прогнозировании категории страховки клиента на основе его демографических данных, образа жизни и региона проживания. Это позволит страховой компании быстрее выделять клиентов с высокими рисками и точнее рассчитывать тарифы. Дополнительно решается задача регрессии (прогнозирование конкретной суммы страховых выплат)

Перед обучением модели данные нужно было подготовить. Числовые признаки (age, bmi, children) заполняем медианой и масштабируем. Категориальные (sex, smoker, region) заполняем самым частым значением и кодируем

Для классификации использован алгоритм KNN. Параметры n_neighbors и weights подбирались через GridSearchCV с 5-блочной стратифицированной кросс-валидацией по метрике ROC-AUC. Лучшими оказались n_neighbors = 9 и weights = 'distance'

На тестовой выборке модель показала Accuracy = 90 % и ROC-AUC = 0,9405. Точность (precision) и полнота (recall) по обоим классам находятся в диапазоне от 0,87 до 0,94, то есть модель почти не ошибается при определении дорогой и дешёвой страховки. Матрица ошибок выглядит так: 126 верно определённых дешёвых страховок, 116 дорогих, 8 ложноположительных и 18 ложноотрицательных

Для прогнозирования суммы выплат был обучен KNeighborsRegressor. Гиперпараметры подбирались через RandomizedSearchCV с 5-блочной кросс-валидацией KFold по метрике neg_mean_absolute_error. Лучшими результатами оказались n_neighbors = 4 и weights = 'distance'

Модель регрессии показала MSE = 34 114 812, RMSE = 5 841, MAE = 3384,67 и SMAPE = 28,77 %. Средняя ошибка показала около 3,4 тыс. долларов. SMAPE 28,77 % говорит о том, что для точных прогнозов по каждому клиенту модель нужно улучшать

На графике «Ожидание и реальность» точки расположены вдоль диагонали, но с заметным разбросом. Модель занижает крупные выплаты и слегка завышает мелкие. Гистограмма остатков смещена вправо от нуля, то есть модель чаще недооценивает реальные расходы

В итоге классификация показала хорошее качество: 90 % accuracy и ROC-AUC 0,94. Этого достаточно для предварительного скоринга клиентов. Регрессия даёт приемлемую, но не высокую точность (RMSE около 5,8 тыс. долларов и SMAPE около 29 %). Для точного расчёта тарифов этого мало. Основное ограничение состоит в том, что KNN плохо работает с разными масштабами и слабо улавливает нелинейные зависимости

Для улучшения модели стоит попробовать градиентный бустинг, добавить новые признаки (например, взаимодействие bmi и smoker) и расширить сетку гиперпараметров. Эти изменения помогут повысить точность прогнозов и сделать модель пригодной для более широкого круга задач
