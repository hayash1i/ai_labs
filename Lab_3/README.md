# Лабораторная работа №3
Цель: построить и обучить модель машинного обучения, которая по данным о клиентах страховой компании определяет, является ли страховка дорогой, а также прогнозирует саму сумму расходов на страховку.

Для анализа взят датасет insurance.csv с информацией о клиентах медицинской страховки. Каждая строка соответствует одному клиенту, а столбцы содержат его возраст (age), пол (sex), индекс массы тела (bmi), количество детей (children), факт курения (smoker), регион проживания (region) и сумму страховых выплат (charges). На основе последнего столбца сформирован бинарный целевой признак is_expensive: 1 — если выплата выше медианы, 0 — если ниже. Классы получились сбалансированными, по 50 % на каждый.

Бизнес-задача заключается в том, чтобы заранее относить клиента к категории с дорогой или дешёвой страховкой. Для страховой компании это важно, поскольку позволяет быстрее выделять клиентов с высокими рисками и точнее рассчитывать тарифы. Дополнительно решается задача регрессии — прогнозирование конкретной суммы страховых выплат, что даёт более точную оценку стоимости обслуживания каждого клиента.

Числовые признаки (age, bmi, children) обрабатываются через импутацию медианой и стандартизацию, категориальные (sex, smoker, region) — через импутацию самой частой категорией и One-Hot Encoding. Вся предобработка собрана в единый Pipeline через ColumnTransformer, поэтому обучение scaler и encoder происходит только на train-выборке, без утечки данных в тест.

В качестве алгоритма классификации использован KNN (KNeighborsClassifier). Гиперпараметры (n_neighbors и weights) подбирались через GridSearchCV с 5-блочной стратифицированной кросс-валидацией, метрика оптимизации — ROC-AUC. Лучшие параметры: n_neighbors = 9, weights = 'distance'.

На тестовой выборке модель показала Accuracy 90 % и ROC-AUC 0,9405. Precision и recall по обоим классам находятся в диапазоне 0,87–0,94. Матрица ошибок: 126 верно определённых дешёвых страховок, 116 — дорогих, 8 ложноположительных и 18 ложноотрицательных. Модель хорошо разделяет классы и может использоваться для предварительной оценки риска.

Для прогнозирования суммы выплат обучен KNeighborsRegressor на том же препроцессоре. Гиперпараметры подбирались через RandomizedSearchCV с 5-блочной кросс-валидацией. Лучшие параметры: n_neighbors = 4, weights = 'distance'.

Модель регрессии показала MSE = 34 114 812, RMSE = 5 841, MAE = 3384,67 и SMAPE = 28,77 %. Средняя ошибка около 3,4 тыс. долларов. SMAPE 28,77 % показывает, что модель улавливает общий тренд, но для точных прогнозов по каждому клиенту её нужно улучшать.

На графике «Ожидание и реальность» точки расположены вдоль диагонали, но с заметным разбросом — модель занижает крупные выплаты и слегка завышает мелкие. Гистограмма ошибок показывает, что распределение остатков близко к нормальному со смещением в отрицательную сторону: модель чаще недооценивает реальные расходы.

Модель классификации показала хорошее качество (90 % accuracy, ROC-AUC 0,94) и может применяться для предварительного скоринга клиентов. Модель регрессии даёт приемлемую, но не высокую точность: RMSE около 5,8 тыс. долларов и SMAPE около 29 % — этого недостаточно для точного расчёта тарифов. Основное ограничение — KNN плохо работает с разными масштабами и слабо улавливает нелинейные зависимости. Для улучшения стоит попробовать градиентный бустинг, добавить новые признаки (например, взаимодействие bmi и smoker) и подобрать более широкую сетку гиперпараметров.
