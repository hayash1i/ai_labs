# Цель работы
Цель работы — изучить, как мультиколлинеарность влияет на линейные модели, и разобраться, как методы Ridge и Lasso помогают с этой проблемой. Также необходимо сравнить результаты моделей и посмотреть, как меняются их веса после применения регуляризации.

# Набор данных и постановка задачи
Для работы выбран датасет Ames Housing Dataset, в котором содержится информация о домах в городе Эймс (США). В нём представлены данные о площади домов, количестве комнат, годе постройки, характеристиках гаража и других параметрах.
Задача заключается в том, чтобы на основе этих данных спрогнозировать стоимость недвижимости (SalePrice).

# Подготовка данных
Для работы были выбраны 16 числовых признаков. Пропущенные значения заполнены медианой. Данные разделены на обучающую и тестовую выборки в соотношении 80 к 20.
Затем все признаки были приведены к одному масштабу с помощью StandardScaler. Также была построена матрица корреляций, которая помогла найти признаки с сильной зависимостью друг от друга. Например, корреляция между площадью гаража (Garage Area) и количеством гаражных мест (Garage Cars) составила 0,89.

# Результаты
В работе были обучены пять моделей: обычная линейная регрессия (OLS), Ridge, Lasso, Lasso с фиксированным значением alpha = 50000 и ElasticNet.
Для Ridge и Lasso было подобрано значение alpha = 100, а для ElasticNet — alpha = 1,0 и l1_ratio = 0,95.
По результатам сравнения моделей получены следующие значения R²:
- OLS — 0,8289.
- Ridge — 0,8283.
- Lasso — 0,8288.
- Lasso (alpha = 50000) — 0,1902.
- ElasticNet — 0,8281.
Первые четыре модели, кроме Lasso с большим значением alpha, показали примерно одинаковые результаты. При этом Lasso с alpha = 50000 обнулил почти все веса, оставив только признак Overall Qual. Из-за этого точность прогноза заметно снизилась.
По результатам анализа видно, что на стоимость дома больше всего влияет его общее качество (Overall Qual). Также важными признаками оказались жилая площадь, площадь подвала и год постройки.

# Вывод
В ходе работы были изучены методы Ridge и Lasso, а также их влияние на линейные модели. Выяснилось, что при небольшом значении регуляризации качество прогноза почти не меняется. Однако слишком большое значение alpha ухудшает результат, так как модель учитывает меньше признаков.
Таким образом, регуляризация помогает изменить веса признаков и убрать часть из них, но важно правильно подобрать её значение, чтобы не потерять точность прогноза.
